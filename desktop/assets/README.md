# Assets

Place icon files here before building:

- `icon.ico`      — Windows installer & taskbar icon (256x256 ICO)
- `icon.icns`     — macOS app icon
- `icon.png`      — Linux + splash screen (512x512 PNG)
- `icon-tray.png` — System tray icon (32x32 PNG)

Free unicorn icon sources:
- https://icons8.com/icons/set/unicorn
- https://www.flaticon.com/search?word=unicorn
